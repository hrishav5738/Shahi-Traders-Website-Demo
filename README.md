# Shahi Trader's Website

Premium responsive Next.js website for M/S SHAHI TRADERS, an infrastructure construction company.

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Documentation

For a detailed explanation of the project structure and the role of every folder, see [ARCHITECTURE.md](ARCHITECTURE.md).

## Stack

- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React Icons

This is a frontend-only UI demo. The contact form, gallery lightbox, project details, and map are placeholders with no backend or database.
